installation

Three ways to get Orbi.

Free and open source. Needs macOS 13 or newer on an Apple Silicon Mac.

01

Download for Mac

Get the disk image, open it, and drag Orbi into Applications. Orbi isn't notarized by Apple yet, so the first time macOS will stop it — open System Settings → Privacy & Security and click Open Anyway. Or use the command, which skips this.

Download Orbi.dmg SHA-256

02

Install with one command

Paste this into Terminal. It checks the download against its checksum, installs Orbi and opens it — no security prompt.

curl -fsSL https://orbi-xi-jet.vercel.app/install.sh | sh

03

Read the script first

Prefer to look before you run? Download the installer, read it — it's short on purpose — then run it yourself.

curl -fsSLO https://orbi-xi-jet.vercel.app/install.sh
less install.sh
sh install.sh
View install.sh
